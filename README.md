# À propos de moi

Étudiant en **2ème année de BUT Informatique** à l'IUT de Nantes, passionné par le développement et l'infrastructure. J'aime autant écrire du code que configurer la machine qui va le faire tourner.

Orienté **backend** (PHP/Symfony, Kotlin) avec des notions **frontend** (TypeScript, React), j'apprends surtout en construisant : un projet déployé pour de vrai, un bout de code qui me fait gagner du temps, ou un serveur qui tourne dans le coin de ma chambre.

🚀 **Alternance à venir chez Lunéos (développeur web full-stack) — rentrée 2026.**
